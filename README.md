About the Repository

This repository contains my practical assignments and programs for the Data Structures and Algorithms (DSA) subject as part of the Integrated MCA curriculum.

The purpose of these assignments is to understand fundamental data structures, learn their operations, and develop problem-solving and programming skills using C++.

All programs are organized into folders according to their respective topics for easy navigation and reference.

Topics Covered

The following topics are covered in this repository:

1. Arrays
   
   - Array operations and implementation
   - Traversal and manipulation

2. Linked Lists
   
   - Singly Linked List
   - Doubly Linked List
   - Linked List operations

3. Stacks
   
   - Stack implementation
   - Push and Pop operations

4. Queues
   
   - Queue implementation
   - Enqueue and Dequeue operations

5. Circular Queue
   
   - Circular Queue implementation
   - Insertion and Deletion operations

6. Searching Algorithms
   
   - Linear Search
   - Binary Search

7. Sorting Algorithms
   
   - Basic sorting techniques

8. Trees
   
   - Introduction to Trees
   - Tree structures and concepts
